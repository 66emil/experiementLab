# Работа над ExperimentLab

Проект состоит из React-приложения, FastAPI API и независимого статистического пакета. Установка и настройка окружения описаны в [руководстве разработчика](docs/development.md).

## Локальная проверка

Перед отправкой изменений:

```sh
npm run check
npm run format:check
uv run ruff check .
uv run ruff format --check .
```

`npm run check` включает TypeScript, production-сборку и Python-тесты. CI дополнительно проверяет миграции и соответствие OpenAPI сгенерированным TypeScript-типам.

## Где менять код

| Задача | Размещение |
| --- | --- |
| Страницы и навигация | `apps/web/src/pages`, `apps/web/src/app` |
| Поведение отдельной функции | `apps/web/src/features` |
| Общие компоненты и API-клиент | `apps/web/src/shared` |
| Сценарии, валидация и хранение | `backend/src/experimentlab/modules` |
| Статистические методы | `packages/statistics/src/experimentlab_statistics` |

Маршруты отвечают за HTTP, сервисы — за сценарии, репозитории — за запросы. Статистический пакет не должен импортировать FastAPI или слой хранения.

## Изменение API и схемы БД

После изменения контракта:

```sh
npm run api:types
```

В коммит включаются и `docs/openapi.json`, и `apps/web/src/shared/api/schema.d.ts`. Сгенерированные типы вручную не редактируются.

Изменения моделей БД сопровождаются новой проверенной миграцией. Выпущенные миграции и исходные файлы версий датасетов не переписываются.

## Статистические изменения

Для нового метода нужны документированные допущения, политика пограничных случаев и численные эталоны из независимого источника. Тест должен проверять результат, а не воспроизводить код формулы. Существующие эталоны: [reference_cases.json](packages/statistics/tests/fixtures/reference_cases.json).

Блокирующие ошибки качества не превращаются в предупреждения ради получения p-value. Пропуски и дубликаты не удаляются молча; автоматического объявления победителя в контракте нет.

## Pull request

Опишите проблему, новое поведение и выполненные проверки. Для заметных изменений интерфейса приложите скриншот; используйте синтетические данные. Не включайте базы, загруженные файлы, `.env`, окружения или зависимости в коммит.

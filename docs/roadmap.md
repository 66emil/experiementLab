# Этапы развития

Этапы 1–4 — работающий локальный MVP. Для этапов 5–9 подготовлены только интерфейсы `UI Preview`; серверная реализация будет добавлена в следующих запросах. Границы и критерии — в [плане будущих модулей](future-features.md).

| Этап | Состояние | Содержание |
| --- | --- | --- |
| **1. Конфигурация и жизненный цикл** | Реализовано для поддерживаемого плана | Черновик, параметры, калькулятор, фиксация плана, draft → running → completed, защита конкурентных записей |
| **2. Загрузка и хранение CSV** | Реализовано | Базовый контракт, проверки строк, лимиты, неизменяемые версии, SHA-256, скачивание |
| **3. Experiment Health** | Реализовано | Пропуски, повторы, пересечение, группы, SRM по сохранённому плану; блокировки и предупреждения |
| **4. Базовые методы** | Реализовано | Две пропорции, Welch t-test, эффект, ДИ, p-value, допущения и независимые эталоны |
| **5. AnalysisRun** | UI Preview | История, конфигурация, версии и причины блокировки; хранение и API ещё впереди |
| **6. Analytics Dashboard** | UI Preview | Контекст запуска, сравнение, распределения и состояния; связь с сохранёнными результатами ещё впереди |
| **7. Отчёт по запуску** | UI Preview | Документ, правила вывода и образец Markdown; формирование и экспорт ещё впереди |
| **8. Bootstrap** | UI Preview | Форма B/seed/percentile и иллюстрации; вычисления, бюджет и эталоны ещё впереди |
| **9. CUPED** | UI Preview | Контракт ковариаты и диагностика; импорт, корректировка и статистический вывод ещё впереди |

## Следующая реализация: этапы 5–9

1. Сначала AnalysisRun: неизменяемая привязка к данным/плану/движку, Health перед вычислением, сохранение истории.
2. Затем Analytics Dashboard и отчёт, использующие один сохранённый результат.
3. Bootstrap с зафиксированным методом ДИ, B, RNG/seed, бюджетом и воспроизводимостью.
4. CUPED с совместимым расширением CSV, проверкой ковариаты и явными ограничениями автоматических проверок.

Preview не создаёт эти зависимости и не подменяет работающий расчёт по запросу. Кнопки исполнения и экспорта отключены.

## Развитие основы

- Планирование непрерывных метрик, неравных групп и кластерной рандомизации, формализация правила остановки.
- Проверка полноты и зрелости наблюдений при наличии корректных временных данных.
- Другие форматы, фоновые импорты, объектное хранилище и сверка файлов с метаданными.
- Точные методы для редких событий, последовательный анализ и множественные сравнения — отдельные статистические задачи.
- Worker и очередь — после измерения нагрузки и выбора ресурсного профиля.

## Общая среда

Авторизация, пользователи, рабочие пространства, права доступа, PostgreSQL в CI, миграции при развёртывании, резервное копирование, наблюдаемость и браузерные e2e в CI. Инфраструктура выбирается под фактические требования к размещению и нагрузке.

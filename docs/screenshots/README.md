# Скриншоты

Все PNG — снимки интерфейса в браузере, а не дизайн-макеты, собранные поверх изображения.

| Набор | Источник значений | Состояние функций |
| --- | --- | --- |
| `dashboard`, `designer`, `analysis`, `health`, `datasets`, `srm-block`, `welch`, `mobile` | Отдельная демонстрационная БД и синтетические CSV, расчёт через реальный API | Реализованные этапы 1–4 |
| `preview-overview`, `preview-runs`, `preview-analytics`, `preview-report`, `preview-bootstrap`, `preview-cuped`, `preview-mobile` | Локальные статические fixtures в `features/preview` | Только оболочка этапов 5–9 |

Preview-значения не получены новыми статистическими методами. Графики являются иллюстрациями, запуск/сохранение/экспорт отключены. Пометка UI PREVIEW входит в каждый снимок будущего модуля.

Desktop Preview снят при ширине 1440 px, mobile — 390 px. Маршруты и границы реализации — в [описании будущих модулей](../future-features.md).

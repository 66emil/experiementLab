# Сравнение двух независимых групп

Независимый пакет `experimentlab_statistics` версии 0.2.0 не импортирует HTTP, БД или CSV. Он реализует сравнение пропорций, Welch t-test и SRM. API читает выбранную версию файла, выполняет Health и затем вызывает метод по типу метрики. Блокирующие ошибки Health запрещают расчёт; предупреждения сохраняются в ответе.

## Контракт и интерпретация

Результат содержит `control`/`treatment`: размеры групп, конверсию или среднее, а также successes для бинарной метрики или выборочную дисперсию для непрерывной. `absolute_effect = treatment − control`, `relative_effect = absolute_effect / control`. Относительный эффект — доля, например 0.10 означает +10%. Для бинарной метрики абсолютный эффект 0.01 отображается как +1 процентный пункт.

Возвращаются двусторонний p-value, доверительный интервал **абсолютного** эффекта, α, метод, статистика, для Welch — степени свободы, а также допущения и причины недоступности. Интервал относительного эффекта не оценивается. α берётся из плана на момент загрузки, SRM использует свой отдельный порог.

ДИ — частотный интервал с номинальным покрытием; он не задаёт вероятность попадания фиксированного эффекта в этот конкретный интервал. p-value не является вероятностью истинности H0, величиной эффекта или готовой рекомендацией. В контракте отсутствуют поля winner, significant и автоматическая рекомендация.

Общие условия: одна строка на независимую единицу, отсутствие пересечения групп, фиксированный горизонт, одна основная гипотеза. Нет поправок на множественные проверки, peeking или кластеризацию. Независимость, отсутствие постселекции и корректность внешнего назначения групп не доказываются по CSV.

## Бинарные метрики

Используется двусторонний pooled Z-test для H0: `p_T=p_C`:

```text
p_C=x_C/n_C; p_T=x_T/n_T; p_pool=(x_C+x_T)/(n_C+n_T)
Z=(p_T-p_C)/sqrt(p_pool × (1-p_pool) × (1/n_C+1/n_T))
p=2Φ(-|Z|)
```

Без поправки на непрерывность. Для нормальной аппроксимации продукт требует минимум 5 наблюдаемых успехов и 5 неуспехов в каждой группе. Это явно заданное консервативное ограничение применимости; точный тест для редких событий ещё не реализован. Формула и независимый пример: [statsmodels proportions_ztest](https://www.statsmodels.org/stable/generated/statsmodels.stats.proportion.proportions_ztest.html).

Интервал — **Newcombe–Wilson hybrid score**, без continuity correction: сначала Wilson-интервалы каждой доли, затем квадратурное объединение односторонних расстояний для разности. Границы ограничены допустимыми −1 и 1. Метод: [statsmodels confint_proportions_2indep](https://www.statsmodels.org/dev/generated/statsmodels.stats.proportion.confint_proportions_2indep.html), `method='newcomb'`. Интервал и pooled-тест используют разные аппроксимации и не обязаны точно совпадать на пороге α.

## Непрерывные метрики

Welch t-test сравнивает средние без предположения равенства дисперсий. Используется несмещённая выборочная дисперсия (делитель n−1):

```text
SE²=s_C²/n_C+s_T²/n_T
t=(mean_T-mean_C)/SE
df=SE⁴ / [(s_C²/n_C)²/(n_C-1)+(s_T²/n_T)²/(n_T-1)]
p=2 × P(T_df ≥ |t|)
CI=(mean_T-mean_C) ± t_(1-alpha/2,df) × SE
```

Моменты считаются с масштабированием для устойчивости, хвосты и квантиль t-распределения — через SciPy. Формулы: [NIST, two-sample t-test](https://www.itl.nist.gov/div898/handbook/eda/section3/eda353.htm); поведение Welch в библиотеке: [SciPy ttest_ind](https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.ttest_ind.html).

Нужна конечная дисперсия; для малой выборки — приблизительная нормальность, для большой — применимость ЦПТ. Малый объём (<30 в любой группе) вызывает предупреждение, но не автоматический запрет при n≥2. Этот порог не гарантирует нормальность. Тяжёлые хвосты, экстремальные выбросы и асимметрия требуют отдельной оценки; автоматического предварительного теста нормальности нет.

## Пограничные случаи

| Ситуация | Результат |
| --- | --- |
| Меньше 2 наблюдений в группе | Описательные оценки, если определены; p-value/ДИ `null`, `unavailable` |
| Меньше 5 успехов/неуспехов для Z-test | Эффекты доступны, p-value/ДИ `null`; строгий отказ от нормальной аппроксимации |
| Обе группы постоянны | p-value/ДИ `null`, даже если константы различны; без ложной определённости |
| Только одна дисперсия нулевая (Welch) | Расчёт по ненулевой дисперсии второй группы, предупреждение |
| Контрольная метрика 0 | Относительный эффект `null`; абсолютный эффект и сам тест независимы от деления на baseline |
| Пропуски, NaN, Infinity на входе пакета | ValueError, без автоматического удаления; через API блокирует Health |
| Численный overflow | Неопределимые поля `null`, явная причина; не сериализуются NaN/Infinity |
| Численный underflow p-value до 0 | Предупреждение; UI отмечает численный предел, а не точную вероятность 0 |

Уровень α должен быть конечным, 0<α<0.5, и представимым в машинной арифметике для уровня 1−α. Некорректные параметры не запускают тест.

## Независимые эталоны

Фиксированные входы и ожидаемые значения находятся в `packages/statistics/tests/fixtures/reference_cases.json`. Ожидаемые значения не вычисляются проверяемой функцией.

- Z-test и Newcombe: отдельный запуск **statsmodels 0.15.0** в временном окружении, не являющемся зависимостью проекта. Для control 5/83, treatment 12/99: Z=1.4078304151258787, p=0.15918129181156992, ДИ=[−0.027909954665286396; 0.14688264097875414]. Дополнительно проверены 56/70 против 48/80 и 10/100 против 20/100, включая знак отрицательного эффекта.
- Welch: опубликованный пример R `t.test` с `[1,2,3]` и `[1.1,2.9,4.2]`, p=0.53619490753126686. Знак t изменён под направление treatment−control.
- ДИ Welch: опубликованные значения R PairedData с tr=0 (обычный Welch), уровнем 90%, неравными размерами групп 11/13. В тесте допускается округление опубликованных чисел. Оба R-эталона находятся в [проверках SciPy](https://github.com/scipy/scipy/blob/main/scipy/stats/tests/test_stats.py), `TestTTestIndMore` и `TestTTestCI`.
- SRM: независимая аналитическая связь χ²₁=Z². При X²=4 p=0.04550026389635842; при X²=25 p=5.733031437583866e−7.

Дополнительно проверяются перестановка групп, масштабирование, пустые и постоянные выборки, нулевой baseline, неконечные значения, сохранность версий и отсутствие автоматического победителя. Пересчёт выполняется по исходным байтам и снимку плана; результат зависит от явно указанной версии движка. История отдельных запусков анализа пока не сохраняется в БД.

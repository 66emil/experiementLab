# Данные для знакомства с платформой

Все файлы содержат **синтетические данные**. Они предназначены для проверки интерфейса и методов, а не для продуктовых рекомендаций.

| Файл | Метрика | Наблюдения | Сценарий |
| --- | --- | --- | --- |
| [user_metrics.csv](user_metrics.csv) | Конверсия | 6 пользователей | Минимальный пример формата; объёма недостаточно для Z-test |
| [registration.csv](registration.csv) | Конверсия | 2 500 control + 2 500 treatment | 12% и 14,6%; пример полного сравнения двух пропорций |
| [revenue.csv](revenue.csv) | Выручка на пользователя | 100 control + 100 treatment | Неотрицательная непрерывная метрика для Welch t-test |

Чтобы увидеть результат:

1. Создайте эксперимент с соответствующей основной метрикой и распределением 50/50.
2. Для исследования достаточно черновика. Чтобы зафиксировать план бинарного эксперимента до импорта, заполните baseline, эффект и даты, запустите и завершите эксперимент.
3. Загрузите файл в карточке или разделе «Данные».
4. В истории версии откройте «Проверки качества», затем «Сравнить метрики».

Для примера регистрации можно использовать baseline 12%, относительный MDE 25%, мощность 80%, α 5%. Ожидаемый эффект в плане и наблюдаемый эффект в файле — разные величины.

Одна строка — один уже распределённый пользователь. При загрузке нового файла создаётся полный снимок, а не дополнение к предыдущему. `control` и `treatment` — значения колонки `variant`, независимо от пользовательских названий групп.
